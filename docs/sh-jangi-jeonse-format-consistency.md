# SH 장기전세주택 공고문 서식 일관성 조사 (49차·50차 실물 대조, 2026-09-01)

목적: MOD-01(공고문→구조화 데이터)을 LLM 없이 규칙기반 파서로 대체할 수 있는지 판단하기
위해, 51차 외에 실제로 확보한 49차(2025.12.15. 공고)·50차(2026.04.27. 공고) 공고문 PDF를
직접 대조했다.

## 결론: 매우 일관적. 회차별 파서가 아니라 "공급방식×면적구간별" 파서면 충분해 보임.

## 완전히 동일한 것 (49차=50차, 51차도 동일 패턴으로 기억됨)

- **문서 골격**: `01|공급일정` ~ `12|주택위치안내` + 별표, 섹션 번호·제목까지 토씨 하나
  안 다름.
- **자산기준표**: 기본/①해당시/②③해당시 3열 구조, 총자산·자동차 2행. 금액만 다름
  (CPI 반영 추정).
- **소득기준표**: 가구원수(1~6인) × %구간(70~200%) 행렬. 열 개수·순서 동일.
- **신생아 가구 가산 조항**: "①2023.3.28. 이후 출생 1명: 10%p" / "②2명 이상: 20%p" /
  "③1명+기존 미성년자녀: 20%p" — 문장까지 거의 동일. 소득 가산표(60㎡ 이하 1·2순위
  /3·4순위+매입형/60㎡초과 3단 구조)도 동일.
- **일반공급(일반) 배점표**: ①서울시 연속거주기간 ②무주택기간(각 10/7/5/3년 구간)
  ③연령(50/45/40/35세) ④부양가족수(5/4/3/2/1인) ⑤-1 청약저축납입횟수(85㎡ 이하)
  ⑤-2 청약예금가입기간(85㎡ 초과) — 6개 항목, 점수구간 경계값까지 동일.
- **주거약자형 배점표**: ①부양가족수 ②서울시거주기간 ③사회취약계층(생계·의료급여
  수급자 / 차상위계층) ④청약저축납입횟수 ⑤장애인(심함/심하지 않음) — 5개 항목,
  경계값까지 동일.
- **재계약 감점**: 3년 이내 -6점 / 5년 이내 -4점 / 그 외 -2점. 동일.
- **면적구간 분기 축**: 공사건설형은 60㎡·85㎡ 경계, 서울시 매입형은 50㎡·60㎡ 경계로
  갈린다 — 이 축 자체가 "공급방식"에 고정된 것이지 회차별로 흔들리는 게 아님.

## 회차마다 실제로 달라지는 것

1. **숫자값**: 소득표 원화 금액, 자산·자동차 한도(CPI 지수화) — 이건 애초에
   program.ts에서 데이터로 분리해뒀으니 파서 설계와 무관.
2. **목차 페이지 번호·별표 개수**: 49차는 별표 2개(별표1 주택소유판정, 별표2 소득·자산
   항목+총자산/자동차 통합), 50차는 별표 3개(총자산/자동차를 별표3으로 분리). →
   **페이지 번호 고정 파싱은 위험, 반드시 섹션 제목/표 헤더 텍스트 기준으로 앵커링해야
   함.**
3. **단지 목록·자치구 목록**: 당연히 회차마다 다름(공급 대상 자체가 다르므로) — 이건애초에 룰 데이터가 아니라 참고정보라 스키마에 영향 없음.

## 설계 시사점

- program.ts를 51차 하나만 보고 짠 게 아니라 처음부터 태그드유니언으로 일반화해둔
  선택이 결과적으로 맞았다 — 실제 회차 간 배점표 항목·구간, 신생아 가산 구조, 감점
  구조가 전부 동일하게 재현됨.
- 2단계(규칙기반 파서) 설계 시 "회차별 브랜치"가 아니라 **"공급방식(공사건설형/매입형)
  × 면적구간"별 브랜치**로 짜면 될 것으로 보임 — 이 축의 가짓수는 유한하고 안정적.
- 파서는 페이지 번호가 아니라 섹션 제목·표 헤더 문자열을 앵커로 삼아야 함(별표 개수가
  회차마다 다를 수 있으므로).
- 이 결론은 **SH 장기전세주택 한 상품 라인에 한정**된다. LH·타 기관·SH의 다른 상품
  (국민임대, 행복주택 등)은 별도로 확인 전까지 동일 가정을 적용하면 안 됨.
